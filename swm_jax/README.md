# JAX python implmentation 

## Install: 

### Conda

`conda env create -f environment.yml` 

### pip 

For CPU builds: `pip install jax`

GPU install options below: 

`pip install -U "jax[cuda13]"`

`pip install -U "jax[rocm7-local]"`
